# Robot learning

Each project lives under `projects/` with its simulator, experiments and demo.

| Project | What you can run |
| --- | --- |
| [SO-101 path learning](projects/so101-path-learning/) | Six MuJoCo arm tasks, trained path selectors, scripted gripper comparisons and the [interactive article](https://dunlichan.com/writings/so101-path-learning/) |

To run the first project on Windows, open **Start SO-101.cmd** inside its folder. The [project README](projects/so101-path-learning/README.md) includes the Linux commands, training instructions and evaluation results. The upstream autoresearch checkout is pinned as an optional submodule.
