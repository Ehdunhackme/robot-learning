# Interactive article

Start `python studio.py` in the parent project. In this directory run `npm ci` and `npm run dev`, then open the printed local URL. Use Node 24. For a production build run `npm run build` and `npm start`.

The featured replays, comparison films, chart and article are included here. Randomized layouts run in the Python studio at `http://127.0.0.1:8766`. Set `SO101_STUDIO_URL` before starting or building Next.js to use a different studio. The serverless adapter in `api/arcbench.py` calls the same physics code in the parent directory.
